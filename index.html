Platform Changelog

Everything added, updated, and enhanced in Vultware

v1.5.0 Latest Release

Changelog System & Navigation Polish

  • Changelog Tab: Added dedicated tab and timeline tracking every project update from inception to current release.
  • Primary Navigation: Reordered filter tabs with Scripts prioritized as the primary homepage landing view.
v1.4.0 Cloud & Public Multi-User

Global Hosting & Live Database Sync

  • Shared Database Backend: Added automatic server syncing (database.json) so posts, updates, and registrations sync globally across devices in real time.
  • One-Click Cloudflare Hosting: Added host_publicly.bat for instant free public HTTPS domain generation.
  • One-Click ngrok Support: Added host_ngrok.bat for developer port tunnels.
  • Local Node Server: Created zero-dependency server.js and start_server.bat with directory listing protection.
v1.3.0 Customization

Appearance Settings & Custom Wallpapers

  • Custom Color Engine: Added 7 instant color presets (Teal, Purple, Pink, Amber, Emerald, Blue, Red) + full RGB custom color picker.
  • Custom Wallpapers: Ability to upload PC images as frosted background wallpapers.
  • Opacity & Blur Sliders: Granular sliders for background transparency and depth-of-field blur.
  • Reset Defaults: One-click button to restore original cyber-teal theme settings.
v1.2.0 Management

Script Editing & Category Streamlining

  • Full Post Editing: Authors and owners can click the ✏️ Edit button to modify titles, descriptions, categories, code, and thumbnails with instant pre-filling.
  • Edit Indicators: Added (edited) status badge to modified scripts.
  • Category Cleanup: Removed redundant Snippet and Module tabs in favor of clean Scripts, GUI, Tools, and Other feeds.
v1.1.0 Visuals

Optional Thumbnails & Image Previews

  • Image Uploads: Added drag-and-drop & file picker for optional script thumbnails.
  • Cover Placement: Thumbnails rendered cleanly at the top of script cards with smooth hover zoom effects.
v1.0.0 Initial Launch

Core Platform & Authentication

  • Owner Pre-seeding: Pre-configured owner account (vult) with full permissions.
  • User Auth: Sign up, sign in, password visibility toggles, and session handling.
  • Lua/Luau Syntax Highlighting: Prism.js code viewer with copy-to-clipboard and code expanders.
  • Search & Filter: Real-time keyword search and responsive dark UI.
